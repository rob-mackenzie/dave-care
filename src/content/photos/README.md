# Photos

Put photos for the site in this folder. On GitHub, use **Add file → Upload files**.

Then add them to a page with:

```md
![The TV remote, with the Home button circled](../photos/tv-remote.jpg)
```

- Use lower-case file names with dashes instead of spaces, e.g. `tv-remote.jpg`.
- Use JPG or PNG. iPhone HEIC photos won't work. Change the iPhone's camera to "Most Compatible", or export the photo as JPG first.
- The words in square brackets describe the photo for anyone who can't see it.
- Don't worry about the size: the site shrinks photos for phones automatically.
